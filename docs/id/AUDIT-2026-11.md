# Audit proyek — November 2026 (setelah 3.8.1)

Cara: membaca kode, memindai pola (grep), menjalankan aplikasi di TV nyata dan emulator, dan memeriksa rilis. Status tiap temuan: **diperbaiki**, **sebagian**, atau **terbuka**. "Belum diuji di perangkat" berarti hanya dikompilasi.

## 1. HP kurang imersif
| Temuan | Status |
|---|---|
| Pratinjau langsung di beranda hanya mengisi strip 16:9 di atas; sisa hero (520 dp) berisi gambar statis, jadi terlihat "muat" bukan "penuh" | **diperbaiki**: pratinjau kini memenuhi seluruh hero (mode isi/crop), scrim tengah digelapkan agar teks tetap terbaca. Belum diuji di perangkat (emulator terlalu lambat dan tanpa internet). |
| Gambar mode potret 16:9 dalam hero memotong sisi kiri-kanan video (wajar untuk mode isi) | diterima; kalau terlalu banyak terpotong, bisa dibuat pilihan "pas/penuh" |
| Halaman saluran dan pemutar potret memakai bingkai terpisah (bukan full-bleed) | terbuka |
| Transisi antarhalaman ada, tetapi tidak ada transisi bersama (shared element) dari kartu ke pemutar | terbuka |
| Pratinjau berputar otomatis memakai **data seluler** tanpa pengecekan | **diperbaiki**: dinonaktifkan di jaringan berkuota; sakelar "Pratinjau langsung di data seluler" di Pengaturan |

## 2. Keandalan
| Temuan | Status |
|---|---|
| Crash di langkah terakhir onboarding setelah data dihapus (bagi dengan nol) | **diperbaiki** di 3.8.1 (ditemukan lewat emulator) |
| Tidak ada tes otomatis untuk `:companion` dan `:launcher` (nol berkas tes); CI hanya menguji `:core` dan `:desktop`. Crash di atas lolos karena itu | terbuka: tambahkan tes asap instalasi-baru di emulator pada CI (buka, lewati onboarding, pastikan tidak crash) |
| Pembaruan di perangkat yang sudah terpasang gagal (laporan) | **sebagian**: pemeriksaan tanda tangan tidak lagi menolak pembaruan resmi yang tanda tangannya tak terbaca; pesan kegagalan kini jelas dan tercatat di log. Penyebab pastinya belum terbukti di perangkat. |
| Rilis perbaikan (3.8.0 → 3.8.1) kini wajib | **diperbaiki** (hanya berlaku mulai 3.8.1) |
| Kerusakan job CI Linux sesekali pada rilis | sementara: dijalankan ulang berhasil; perlu dipantau |

## 3. Keamanan
| Temuan | Status |
|---|---|
| Token pairing HP-TV disimpan di SharedPreferences biasa (token akun sudah disegel Keystore) | terbuka: pindahkan ke Keystore |
| Konfigurasi jaringan mengizinkan HTTP polos secara global (perlu untuk TV lokal dan stream IPTV); domain Tahoe sudah dilarang | diterima, didokumentasikan |
| Komponen yang diekspor dikunci izin sistem (aksesibilitas, notifikasi, `Config` hanya shell adb) | baik |
| Akun: scrypt, token ber-hash, pembatasan percobaan, HTTPS wajib, enkripsi saat disimpan | baik; enkripsi hanya sisi server (diketahui) |
| Pembatas login memori tak terbatas | **diperbaiki** |
| `SHA256SUMS` rilis sebelumnya tidak memuat APK Standalone | **diperbaiki** (3.8.1 lengkap) |

## 4. Kualitas dan perawatan
| Temuan | Status |
|---|---|
| Berkas besar: `I18n.kt` 3,7 rb baris, `LiveTv.java` 1,6 rb, `Profile.kt` 1,4 rb, `Live.kt` 1,3 rb | terbuka: pecah bertahap |
| Teks tertanam di kode (HP: 2, TV: 2) | hampir bersih |

| Build harus dijalankan terpisah agar tidak muncul galat metadata Kotlin palsu setelah `:core:test` | catatan pengembang |

## 5. Urutan yang disarankan
1. Uji hero penuh dan pengecekan data seluler di HP nyata.
2. Tes asap instalasi-baru di CI (mencegah kelas crash seperti di 3.8.0).
3. Pairing token ke Keystore.
4. Halaman saluran dan pemutar potret full-bleed + transisi bersama.
5. Pecah berkas besar.
