# Home+ — ekosistem Tahoe di rumah (gratis, open source)

Tujuan: TV, HP, dan Mac terasa satu keluarga, seperti ekosistem Apple, tanpa akun wajib. Fitur yang memakai akun Tahoe (opsional, server sendiri) memakai akun itu; sisanya jalan lewat jaringan rumah.

| Fitur | Seperti apa di Apple | Status | Catatan |
|---|---|---|---|
| **Lanjutkan di perangkat lain (Handoff)** | Handoff | **TV: ada** · HP: mengirim | Tiap perangkat mengabarkan apa yang sedang ditonton; perangkat lain menawarkan "Lanjutkan: RCTI". Server menyimpan tersegel, kedaluwarsa 6 jam. Sudah dicek di TV; HP baru dikompilasi. |
| Lempar dari HP ke TV (Tahoe Connect) | AirPlay | ada | `sessionLoad`, kartu TV di layar Remote |
| Notifikasi dan musik HP di TV | Continuity | ada | |
| Profil, foto, wallpaper, tampilan sinkron | iCloud | ada | akun Tahoe |
| Remote dari mana saja | | ada | tunnel terenkripsi |
| **Lanjutkan di Mac / HP** (sisi menerima) | Handoff | berikutnya | kartu "Lanjutkan dari TV" di Beranda HP dan desktop |
| **Cari perangkatku** | Find My | rencana | bunyikan TV atau HP dari perangkat lain |
| **Keluarga** | Family Sharing | rencana | anggota keluarga, daftar tonton bersama, profil anak per anggota |
| **Waktu layar** | Screen Time | rencana | batas harian per profil anak, laporan mingguan ke orang tua (ada dasar di Kids) |
| **Tonton bersama** | SharePlay | rencana | beberapa perangkat menyetel saluran yang sama berbarengan |
| **Foto jadi screensaver** | Photos | rencana | wallpaper dan foto akun tampil di screensaver TV |
| **Game keluarga** | Arcade | rencana | kuis dan tebak-tebakan, HP sebagai kontroler lewat LAN/tunnel |
| **Olahraga aktif** | Fitness+ | rencana | sesi latihan terpandu dengan timer dan ritme; sensor HP opsional, tanpa unggah kamera |

Prinsip: semuanya opsional, tidak ada yang memaksa login, data di akun terenkripsi di server milik pengguna, dan setiap fitur punya sakelar sendiri di Pengaturan.
