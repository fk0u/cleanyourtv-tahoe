# Keamanan

Menemukan celah keamanan (misalnya akses ke TV tanpa pairing, kebocoran token, atau eksekusi perintah dari jaringan)?
**Jangan buka issue publik.** Laporkan secara privat lewat [GitHub Security Advisories](https://github.com/fk0u/cleanyourtv-tahoe/security/advisories/new).

Sertakan versi, platform, langkah untuk mengulang, dan dampaknya. Laporan akan ditanggapi secepatnya dan diperbaiki di rilis berikutnya.

Catatan desain: server HP ↔ TV (port 8765) dan server IPTV desktop (port 8088) dimaksudkan hanya untuk jaringan lokal (LAN). Jangan meneruskan port ini ke internet.
